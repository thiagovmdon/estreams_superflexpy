# NeuralHydrology LSTM Raw Run Directories

This directory contains the **raw NeuralHydrology training outputs** for all LSTM experiments, organized by random seed. Each subdirectory is a standard NeuralHydrology run folder (config, training logs, model weights, predictions).

**These files are not tracked in this GitHub repository.** Download them from the Supporting Information Zenodo archive:

> Medeiros do Nascimento, T. V. (2026). Data from "Assessing the Impact of Geological Map Detail on Process-Based and Data-Driven Hydrological Models" (0.1) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.18392387

Place the downloaded seed folders directly under `results/LSTM/` before running Part-6 (figures and analysis).

---

---

## Run counts per folder

| Folder type | Runs per seed | Breakdown |
|---|---|---|
| `03_seedXX/` | 25 | 5 geology experiments × 5 spatial CV folds |
| `03_seedXX_10/` | 50 | 5 geology experiments × 10 spatial CV folds |
| `03_time_seedXX/` | 25 | 5 geology experiments × 5 folds (space-time transfer) |

The **5 geology experiments** are:

| Label | Description |
|---|---|
| `reg` | Regional-scale geology (BD LISA / high-resolution national maps) |
| `con` | Continental-scale geology (IHME-1500) |
| `glo` | Global-scale geology (GLiM) |
| `nog` | No geology — baseline, no permeability attributes |
| `ran` | Random geology — Randomly-sampled permeability fractions |

## Example run path

```
results/LSTM/03_seed28/moselle_con_seed28_01_1701_160651/
```

- `03_seed28` — seed group (5-fold)
- `moselle_con_seed28` — experiment (`con` = continental), seed (`28`)
- `01_1701_160651` — fold index and timestamp (NeuralHydrology naming convention)
